# 兰台 Lantai

如今，许多工作都交给了 Agent：开发产品、排查问题、起草邮件、做实验、写文档。人把问题说清楚，Agent 很快就把事情做完。一天下来，工作的过程大多留在了对话里。

Agent 能替我们做出很好的结果，却没法替我们度过这一天。会话之外做了什么，事情最后成没成，自己怎么看这件事，这些只有人自己知道。

兰台把两者放进同一份日志。它读取 Claude Code、Codex CLI 等 Agent 留在本机的会话，由模型起草日报，再汇总成周报和月报，每条结论都能追溯到原始对话。你在旁边写下会话里没有的部分：当天的随记、项目的手记，或者对某条要点的批注。两种笔迹分得清，重新生成也不会改动你写下的字。数据都留在本机：兰台只在生成时把脱敏后的素材发给你选的模型，或在你要求时去 GitHub 查看新版本，此外不联网。

这份记录对 Agent 也许没什么用，对项目的完成也许也没什么用，但对人有用。翻开日报、周报、月报，能看到自己和 Agent 一起做成了许多事，有些是以前没想过能做到的。这份意义属于自己。兰台也是一次尝试：人和 Agent 怎样一起工作，又怎样一起留下记录。

兰台是汉代宫中收藏典籍和档案的地方，班固曾在此校书修史。兰是兰花，清雅内敛，自有其香。把每天零散的工作收拢、整理、存档，正是这个应用想做的事。英文名 Lantai 取自拼音。
