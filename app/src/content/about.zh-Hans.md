# 兰台 Lantai

如今许多工作都交给了 Agent，一天下来，工作的过程大多留在了对话里。可是会话之外做了什么、事情最后成没成、自己怎么看，这些只有人自己知道。

兰台把两者放进同一份日志。它读取 Claude Code、Codex CLI 等 Agent 留在本机的会话，由模型起草日报，再汇总成周报和月报，每条结论都能追溯到原始对话；你在旁边写下会话里没有的部分。两种笔迹分得清，重新生成也不会改动你写下的字。数据留在本机：兰台只在生成时把脱敏后的素材发给你选的模型，或在你要求时检查更新，此外不联网。

这份记录对 Agent 也许没什么用，对人却有用：翻开它，能看到自己和 Agent 做成的许多事。

兰台是汉代宫中收藏典籍和档案的地方，班固曾在此校书修史；兰是兰花，清雅内敛。把每天零散的工作收拢、整理、存档，正是这个应用想做的事。
